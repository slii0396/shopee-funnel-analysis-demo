# E-commerce Funnel and Page Diagnosis Demo

这是一个模拟电商业务分析项目，用于展示如何定义漏斗口径、用 SQL 比较渠道与设备表现，并将结果转化为可验证的产品假设。

> 重要说明：本项目不包含 Shopee 内部数据，也不代表 Shopee 官方项目。所有记录均由脚本生成，仅用于展示分析方法。

## 分析口径

- 访问：产生有效 session；
- 加购：session 内至少发生一次 add-to-cart；
- 下单：session 内完成 order；
- 单页退出：仅访问一个页面后离开；
- CTA 点击：点击页面核心行动按钮。

## 运行

项目只使用 Python 标准库：

```bash
python analysis.py
```

运行后会在 `results/` 中生成渠道指标、设备指标和摘要。

## 演示结果

- 推荐渠道订单率：14.0%；
- 移动端单页退出率：46.1%。

## 产品假设

1. 推荐流量已经具备较高意图，可优先优化落地页与商品信息的一致性；
2. 移动端退出率较高，应检查首屏加载、CTA 可见性、信息层级与页面性能；
3. 模拟数据只能支持分析流程演示，不能用于真实业务归因或商业决策。
